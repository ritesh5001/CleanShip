One-line: renders a Lucide glyph at the brand's 1.75px stroke weight — CleanShip has no proprietary icon set, so Lucide (CDN) is the sanctioned substitute.

```jsx
<Icon name="anchor" size={24} color="var(--brand)" />
```

Requires `<script src="https://unpkg.com/lucide@0.470.0/dist/umd/lucide.js"></script>` on the page. Common names in this system: anchor, ship, waves, droplets, shield-check, phone-call, mail, map-pin, clock, arrow-right, check, spray-can, paintbrush, container.
